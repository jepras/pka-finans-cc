# Spørg dine tal

Øvelse 2 i workshoppen. Guiden med alle prompts ligger i `../session2-guidet-opgave.html`.

Kort version:

```
bun install
bun run dev        # http://localhost:3000
bun run kontrol    # kører de gyldne spørgsmål
```

Uden `.env` kører appen i mock-tilstand. Kopiér `.env.example` til `.env` og indsæt nøglen for at bruge Claude.
